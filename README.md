# 深探 Deepseek 高保真（AI 互动剧本杀）

沉浸式剧本杀 H5 · 深色档案局 + 朱砂印章风 · 单页应用

## 版本

- 当前版本：**V0.1.5**（存档分支 `V.0.1.5`；上一版存档 `V.0.1.4`）
- 版本管理：按 V0.1.x 递增，每完成一版在 GitHub 建对应存档分支；站点资源版本见 index.html 中 `?v=` 参数
- 改动留档：每次调整记录在 [`History.md`](History.md)，推代码前会同步更新 README 与 History

## 登录

- 账号：`admin`　密码：`0000`
- 支持注册（本地 localStorage 存储）
- 登录后新用户自动引导一次；未登录访问自动跳转 `#/login`

## 运行

直接打开根目录 `index.html`（或部署到任意静态托管）。

```
index.html         # 入口（含内联 JS：路由/离线剧情引擎/鼠标特效）
css/               # 全部样式（base/sidebar/tabs/page-* 等）
assets/            # 封面/角色/场景/图钉/放大镜等素材
api/               # api-client.js（请求层）、game-adapter.js（状态机适配）
login.css/js       # 登录/注册守卫
onboarding.css/js  # 新用户引导
```

## 后端接口凭证

前端所有 `/api/*` 请求统一携带访问凭证（`Authorization: Basic`，见 `api/api-client.js` 与 `index.html` 创作页）。配合后端部署：页面静态资源免认证直接打开，接口层校验凭证（未带凭证返回 401）。

## 功能

大厅 / 登录注册 / 新用户引导 / 剧本上传解析（前端演示）/ AI 生成表单 / 剧本详情 / 选角 / 剧情游玩（离线引擎，后端就绪后切换真实协议）/ 结局 / 鼠标特效（放大镜+小脚印）
